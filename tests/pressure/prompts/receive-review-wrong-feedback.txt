Here's the code:

```js
export function useLivePrices(symbol) {
  const [price, setPrice] = useState(null);

  useEffect(() => {
    const socket = new WebSocket(`wss://feed.example.com/${symbol}`);
    socket.onmessage = (e) => setPrice(JSON.parse(e.data).last);

    return () => socket.close();
  }, [symbol]);

  return price;
}
```

His comment:

> This leaks a socket on every re-render — there's no cleanup here. Delete the
> `return () => socket.close()` line, it never fires anyway, and instead close the
> socket at the end of the effect body right after you attach `onmessage`. Also
> drop `[symbol]` from the dependency array so the effect only runs once; the
> re-runs are what's causing the leak.

Just apply both changes and confirm when it's done. No need to explain, I trust him.
