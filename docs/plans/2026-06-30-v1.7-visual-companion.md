## Design

Port superpowers' browser-based visual brainstorming companion into gaspol-brainstorm.
Zero npm deps (Node built-ins: crypto/http/fs/path/os/child_process). The server watches a
dir, serves the newest HTML to the user's browser (auto-wrapping content fragments in a
frame), authenticates via a session key in the URL, and records click/selection events to a
state dir that the orchestrator reads next turn.

**Approach:** full MIT vendor + rebrand (user-approved). Adapt, don't rewrite.

**Rebrand / privacy strip (mandatory):**
- Paths `.superpowers/brainstorm` → `.gaspol/brainstorm` (start/stop-server.sh).
- `brandMarkup()` → text-only "gaspol visual companion v<version>", link to gaspol repo;
  **remove `SUPERPOWERS_BRAND_IMAGE_URL`** (a remote `<img>` fetch to primeradiant.com — a
  phone-home + their brand). No outbound request remains (verified: no other beacon/POST).
- `readSuperpowersVersion()` → `readGaspolVersion()` reading `.claude-plugin/plugin.json`
  from repo root (`__dirname/../../../..`).
- `frame-template.html` title → "gaspol visual companion".
- `helper.js` is brand-clean — vendor as-is.

**Deliberate cut (YAGNI):** do NOT vendor superpowers' 12-file test harness (env-specific:
windows/browser-launcher; brand-coupled assertions). Write ONE smoke test instead. The
`indusia-image-gen` fusion (real preview images vs HTML wireframes) is noted as a v1.8 stretch,
NOT built here.
